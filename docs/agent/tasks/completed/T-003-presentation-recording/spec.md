# T-003 逐页演示录制与 MP4 导出

风险等级：中

## 目标
在现有 Presenter 中录制每页麦克风声音、幻灯片画面与鼠标轨迹；支持预览、单页重录、持久保存，以及按页顺序导出完整 MP4。

## 约束
保留工作树已有修改；单 agent 执行。支持 Typst 和 PDF Presenter。
录制时禁止切页，保存成功才替换旧片段；内容改变的页必须重录后才能导出。
录制需要浏览器麦克风授权；只录幻灯片及指示点，不录讲稿或操作界面。
录制片段属于项目运行状态，不进入 Git 版本；导出使用 FFmpeg H.264/AAC。

## 验收标准
frontend 中 npm test、npm run build 返回 0。
浏览器真实 MediaRecorder 冒烟覆盖两页录制、鼠标移动、预览、单页重录、刷新恢复、完整导出。
后端测试覆盖项目隔离、原子替换、缺页/过期拒绝、真实 FFmpeg MP4 合成和媒体流检查。
文档检查返回 0。不会自动部署线上工作区。
