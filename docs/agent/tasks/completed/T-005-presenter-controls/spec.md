# T-005 演示镭射与讲稿显示控件

风险等级：中

## 目标
仅主鼠标键按住时显示镭射点，投影与录制视频一致；可隐藏/恢复下一页预览，
隐藏时讲稿占满右侧；可调节讲稿字号并保留显示偏好，部署至现有线上服务。

## 约束
保留已有修改、用户项目与会话；不修改讲稿内容。沿用 Presenter 现有视觉风格。
遵循 D-001、D-002；候选验收后部署，保留回退容器/镜像。

恢复、字号改变及刷新保留；真实录制导出检查按住时红点出现、松开后消失。
公网界面验证新控件可用；部署过程保留工作区挂载与用户文件。
文档检查和 git diff --check 返回 0。
