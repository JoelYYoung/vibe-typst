# T-002 joelyang 原生 ARM64 无损迁移

风险等级：高
（工作区运行环境切换）。用户已明确授权迁移。

## 目标
让 joelyang 的 Codex 0.160.0 在原生 ARM64 工作区启动，保留项目、Codex/Claude
历史、认证、配置和原有 x86 二进制目录；保留旧容器供回滚。

## 决策与约束
遵循 D-001。不修改其他用户容器，不清理共享 Docker 存储，不将凭据构建进镜像。
新镜像先使用工作区副本验收，再进行短暂切换。全部原始数据保留私有备份。
不将此前连接卡顿的具体根因归因于 QEMU，除非获得可复现证据。

## 验收
原生 uname、Python、Typst、resolver、Codex 和 Claude 工作；交互 codex --yolo
启动不再出现 os error 38；旧会话可续接；迁移前文件清单全部存在且内容一致
（运行状态文件单独说明）；公网项目、编辑、刷新和终端可用；自动建容器不再强制 amd64。
