# T-015 录制栏导出进度与参考选择 UI

风险等级：低

## 目标
录制模式中进度固定在同一录制栏右侧；退出该栏仍保留后台任务状态入口。
参考声音改为与现有深色 UI 一致的选择菜单和上传控件，文字精简。

## 约束
沿用 D-003、D-005、D-006；不改变导出/取消/模型处理行为。
保留后台任务和原文档/录音/成品，以及独立账户草稿。
参考选择保持页数、上传、键盘、焦点及窄屏可用。

## 验收
前端构建与既有单元检查；Typst/PDF 浏览器测试录制栏同排右侧进度、
退出后浮条、选择页/上传/键盘与 Escape/窄屏，无页面错误。
上线时避开运行中的导出，保留文件与挂载；公网 UI 验证后推送 GitHub。
