# T-014 后台视频导出

风险等级：中

## 目标
导出任务独立于演示窗口和浏览器存活；显式取消停止 FFmpeg 和模型推理。
服务端保存状态，重新进入项目恢复进度和下载，活动任务阻止空闲回收。
简洁的统一进度条、页数/阶段及图标取消，适配窄屏。

## 约束
遵循 D-002、D-003、D-005；保留原录音、文档、挂载与独立账户草稿。
上线前确认没有正在处理的用户任务，保留已完成的现有导出。
模型取消只作用于匹配任务，不重启共享模型服务来取消。

## 验收
后端取消/持久化/隔离/空闲保活测试；真实 FFmpeg 取消与新任务完成。
模型真实推理取消、之后任务成功；前端构建及 Typst/PDF 浏览器验收。
浏览器退出演示和关闭/重开网页后任务继续；网络故障不宣告失败。
公网 UI/功能冒烟；构建部署保持用户文件与挂载；GitHub 推送。
