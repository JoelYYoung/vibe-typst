# T-007 录制镭射与固定预览时长

风险等级：中

## 目标
新录制镭射采用投影相同的红芯、白圈、红色光晕和阴影，按 720p 参考同比
放大到 1080p。预览为旧/新片段补足固定时长和 seek 索引，不改变原媒体。
沿用原生视频控件，以固定总时长区分播放/缓冲进度，上线并保留原项目。

## 验收标准
前端测试/构建及后端录制回归返回 0；真实浏览器 Typst/PDF 录制与 MP4
像素检查核心尺寸/白圈/光晕，松开后消失；预览 metadata 立即给出有限时长，
播放/seek 后保持固定，HTTP Range 有效；缓存失败/复用/符号链接拒绝。
部署保持原挂载及文件哈希一致，公网检查新版资源，文档/差异检查通过。

相关决策：D-001、D-003。
