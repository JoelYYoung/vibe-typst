# T-012 可选模型降噪与统一音色

日期：2026-10-08
风险等级：中

## 目标
完整视频导出可选择模型降噪及 Seed-VC 统一音色；先降噪后统一音色，最后沿用响度均衡。
模型与常规应用依赖分离，按需安装，机器没有可用模型时正常导出仍可用。
统一音色使用一页录音或上传的参考音频；不修改原录音、页面绑定或单页预览。

## 相关决策
D-001、D-003。

## 约束
保留独立账户草稿和所有工作区数据。模型缓存及大输出按当前 External 存储指南配置。
模型文档指定目录目前为空；降噪模型选择待用户补充，先实施独立导出/Seed-VC 接口。
冻结导出输入及参考声音；模型失败须明确失败，不能悄悄改用普通音频。
模型服务按需配置，不在浏览器自动安装软件或在普通导出自动下载权重。

## 验收
后端验证默认导出、可用性、非法选项、参考上传/快照、处理顺序、失败恢复与时长保持。
浏览器检查完整/部分录音导出弹窗、可选模型状态、参考选择、键盘焦点与窄屏。
可选安装文档/脚本和模型服务经过实际检查；区分协议测试与真实模型推理。
上线及 GitHub 同步时只发布本任务改动并核验保留工作区文件。
