# T-013 镜像内置模型与精简导出界面

日期：2026-10-08
风险等级：中

## 目标
默认Docker/Podman工作区镜像包含DPDFNet与Seed-VC运行环境、源码和权重。
界面依据实际加载/推理检测展示各模型可运行性；不可运行不可选，原声导出可用。
导出弹窗只保留必要选项、可运行状态、参考音频、缺页警示和操作；详情放悬浮提示。

## 相关决策
D-003、D-004（本任务新决策取代安装方向）。

## 约束
保留账户草稿与用户文件/录音。镜像不含服务token；运行时生成私密配置。
模型检查/失败不阻塞普通编辑和原声导出，不在导出时下载权重。
可继续使用现有私有宿主机MPS服务加速；没有配置时使用镜像内置运行时。
存储按当前Mac指南检查，不迁移现有Docker存储路径。

## 验收
实际Linux ARM64镜像含模型/依赖/权重，离线通过模型推理并暴露真实能力。
检查中、仅降噪可用、两模型可用、失败状态与控制禁用符合结果。
最简弹窗页/上传参考与缺页导出、键盘/窄屏浏览器验证通过。
必要回归检查、线上模型状态及文件挂载保留通过；推送只含本任务。
