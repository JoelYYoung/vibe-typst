# T-009 部分录制导出与确认弹窗

日期：2026-10-06
风险等级：中

目标：已有至少一页有效录制时允许导出。未录制页按页序跳过，导出前用应用内美化弹窗列出页码和处理方式，明确取消/继续导出；禁止浏览器默认 confirm/alert。
相关决策：D-001、D-003。
约束：过期录制仍要求重录；确认只授权跳过当时列出的页，其他页在并发清除后不得静默跳过。保持不可变导出快照、媒体/稳定绑定隔离和全录制直接导出。保留独立账户草稿与用户工作区数据。
验收：前端单测与构建退出 0；后端覆盖缺页确认、空录制拒绝、过期拒绝、顺序和不可变快照；真实 Typst/PDF 浏览器测试取消/Escape/焦点、部分导出音视频和下载有效性；截图复核弹窗。按既有授权上线并推送 GitHub，同步保留回退容器和原文件哈希。
