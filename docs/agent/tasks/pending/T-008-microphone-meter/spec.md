# T-008 实时麦克风电平与 GitHub 更新

风险等级：中

## 目标
录制时工具栏同一行右侧显示麦克风实时电平与动态条。采用实际录入 RMS 的
-60..0 dBFS，而非物理声压；不监听到扬声器、不新增权限，停止释放分析资源。
验证、上线，并将本轮录制/演示/连接/原生部署更新推送现有 GitHub main。
账户中心独立草稿与未关联设计文档留在工作树，不进入此次提交。

## 验收标准
前端单测/构建通过；真实 Typst/PDF 麦克风音调增益改变/静音使电平改变，
同一行右对齐、停止后消失，原录制/导出仍通过。提交树独立构建、后端全套
测试通过；公网新资源、文件保留；GitHub main 与提交一致且无凭据/用户数据。
