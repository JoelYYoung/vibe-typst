# T-011 工作日志

## 2026-10-07 开始
现状：每页重新编码后直接拼接，仅重采样/补音轨尾部，没有统一响度。
方案：FFmpeg loudnorm 两遍测量/应用，目标 -16 LUFS、-1.5dBTP，LRA 50 使线性增益优先保留说话强弱；需要峰值控制时允许 loudnorm 动态回退。分析与应用使用相同时间裁剪/补齐和 stereo 48kHz 输入，最终输出明确 48kHz，以避免单声道听感和动态模式重采样差异。非有限测量（纯静音或不足测量长度）保留音频，不构造无效参数。依据：https://www.ffmpeg.org/ffmpeg-filters.html#loudnorm 和本机 ffmpeg filter help。
下一步：实现导出过滤器并用独立 PCM RMS 验证跨页音量差、段内强弱和静音/极短音轨；然后隔离全套、Docker 浏览器验收与上线。

## 2026-10-07 用户追加降噪
将轻度 afftdn FFT 底噪抑制加入响度测量/应用的同一输入链，先降噪后均衡，避免直接放大底噪；候选 nr=8、nf=-50、tn=1、gs=5，验证降噪比和延迟。依据：https://www.ffmpeg.org/ffmpeg-filters.html#afftdn。已完成原响度实现 22 项测试，包括独立 ebur128 -16 LUFS、PCM 差异收敛与静音/短片段；新降噪加入后必须重新验收。

降噪原型稳定噪声/人声比例改善约 6.9dB，发现 afftdn 固定两跳缓存（25ms），前置尾部补齐并裁剪/重置 PTS 补偿；脉冲测试确认首部与尾部样本保留且位置误差不超过 2 个样本。降噪加入后原 6dB 强弱测试测得 6.56dB；谱降噪对弱音略多衰减，故将该验收允许偏差从纯增益的 0.4dB 调整到降噪的 1dB，仍明确禁止压平讲话强弱。

Linux 候选检验发现弱半句间 RMS 相差 0.55dB；该窗口不是用户要求的整页平均，降噪对弱声不同处理会影响局部比例。将跨页判定改为完整 4 秒片段的 RMS 平均，继续分别校验段内 6dB 强弱及独立 ebur128 -16 LUFS，避免把自然轻重误当作平均音量。
