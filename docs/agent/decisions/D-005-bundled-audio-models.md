# D-005 默认镜像内置音频模型

日期：2026-10-08
取代：D-004

依据用户最新要求，Docker/Podman工作区默认包含隔离的DPDFNet/Seed-VC依赖、
固定源码和权重，无需用户另行安装。模型独立于应用Python环境。
容器运行时生成私有令牌和临时配置，镜像不能包含认证秘密。
界面实际检测模型加载与推理结果，检查中或失败时禁用对应模型；
模型检查和失败不阻塞普通工作区或原声导出。运行服务离线，不自动下载。
默认使用镜像内的CPU运行时；显式配置可使用私有宿主机MPS/CUDA加速。
界面保留必要状态和选项，详细原因放悬浮提示，不要求用户理解部署细节。
处理顺序仍为DPDFNet降噪、Seed-VC统一音色、响度均衡，参考及输入冻结。
原音视频、单页预览、源内UUID页面绑定保持，模型失败明确失败。
固定研究案例配置与小末端采样修整沿用，不做变速，也不保证逐音素一致。
