# D-007 录制绑定使用源码 UUID 的实际渲染页元数据

日期：2026-10-09
取代：D-003

继承 D-003 的文档内 UUID 注释、不可变录制片段、内容校验及安全迁移规则。
源幻灯片的 UUID 仍随 opener 移动/删除，准备时仅批量插入/修复注释。
Touying 的显示计数不能当作源码序号：标题/焦点页可冻结，溢出续页可递增。
在与主文件同目录的临时查询副本中，为每个显式调用的页面 preamble 添加
不可见 UUID/overlay/物理页元数据，执行原包装器、原参数及原 preamble。
查询结束删除副本，不改写用户源码或预览。绑定只接受完整、唯一的实际页面映射。

普通页继续使用 UUID-overlay，保持既有录制兼容；同一 overlay 的溢出页追加
局部续页序号 UUID-overlay-overflow。这些序号与其他幻灯片的输出页码无关。
同张幻灯片内部改变分页仍由内容哈希判断是否需要重录，不猜测无法证明的归属。
PDF 继续使用页码与内容哈希。媒体仍保存在 .tcb/recordings/，不进入版本历史。
导出生命周期及模型处理遵循 D-005、D-006，录制/清除/导出期间固定输入规则不变。
