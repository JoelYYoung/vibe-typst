# D-003 Typst 录制跟随源文档内稳定标识

日期：2026-10-05
取代：D-002

Typst 的每张显式 Touying 幻灯片在 opener 同行保存稳定 UUID 注释；
整张幻灯片移动/删除时标识随源代码移动/删除。渲染子页使用 UUID + overlay，
不使用整个文档的输出页码识别录制。PDF 保留页码绑定与内容哈希校验。
准备录制显式批量插入 CRDT 注释，不重写整篇文档；复制造成的重复 UUID 重新分配。
编译器发布与 SVG 同批次的源快照，拒绝将新源标识套到旧预览上。
旧片段仅在内容哈希唯一匹配时迁移；不能证明归属的媒体保留。

每页保存独立不可变音视频与带时间戳的归一化镭射轨迹；只在按住时显示镭射。
浏览器冻结画面，不录操作界面及讲稿。`.tcb/recordings/` 保存媒体，文档路径隔离。
Typst 源中的 UUID 是媒体关联索引；媒体仍作为运行状态排除于 Git 版本之外。
完整保存后原子替换稳定引用，失败保留旧片段；删除只清除目标引用和该片段。
内容变化标记过期，完整导出前要求重录；幻灯片重排只重映射当前页名。

MP4 固定 FFmpeg H.264/AAC、1080p、30fps，一次运行一个导出，短请求轮询。
导出启动时硬链接固定片段，重录/清除不改变在途导出；下载只匹配当前全部片段。
服务重启后重新导出。讲稿字数按整场目标时长比例给出参考，不预测实际语速。
