# D-002 演示录制使用独立页面片段

日期：2026-10-05

每个文档的每一渲染页保存独立、不可变的音视频片段及带时间戳的归一化鼠标轨迹。
浏览器使用冻结的幻灯片画面和麦克风录制；操作界面及讲稿不进入视频。
项目 `.tcb/recordings/` 保存片段，文档相对路径区分同项目下的不同主文件。
片段是运行状态，沿用 `.tcb/` 的 Git 排除，避免媒体加入幻灯片版本历史。

新片段及元数据完整保存后原子替换页面引用，失败时保留旧片段。
页名和渲染内容哈希共同校验；改变的页必须重录后才能完整导出。
PDF 的预览 generation token 不作为页面内容哈希，录制端单独计算页面哈希。

MP4 导出固定使用 FFmpeg H.264/AAC、1080p、30fps；服务端一次运行一个导出。
导出启动时硬链接固定所有当前片段，因此并行重录不改变正在导出的视频。
导出任务通过短请求轮询，避免工作区代理的长连接超时。
浏览器只提供与当前全部片段匹配的导出下载入口；服务重启后重新发起导出。
