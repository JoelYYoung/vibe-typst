# D-006 导出任务独立于浏览器

日期：2026-10-09

导出提交后由服务端执行；演示窗口、网页和客户端连接都不拥有取消权。
只有针对所属文档的显式取消请求才设置取消信号；FFmpeg 子进程与模型
逐帧/逐步协作停止，清理后才发布终态并释放运行名额。
控制面回收空闲工作区前检查后台导出，并保留相关用户会话及项目容器。
状态原子保存于文档录制目录，网页重入恢复进度，已完成输出在服务重启后可读。
服务器异常重启中的未完成任务明确失败，可重新提交；不伪装已完成。
讲稿、UUID 页面关联、冻结输入、原录音和单页预览仍遵循 D-003、D-005。
当前录制工具栏保持匹配当前片段的下载规则；任务浮条提供对应冻结快照结果。
模型取消按私有随机请求 ID 隔离，不通过终止共享服务影响其他工作区。
