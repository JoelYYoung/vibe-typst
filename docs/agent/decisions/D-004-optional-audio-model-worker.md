# D-004 导出音频模型独立可选安装

日期：2026-10-08

常规应用、容器及原声导出不依赖 PyTorch 或模型权重。模型由独立私有服务承载；
宿主机可直接使用 MPS/CUDA，普通工作区通过服务端配置的 URL/令牌接入。
浏览器只获取能力状态，不访问模型令牌，也不执行机器上的软件安装。
导出选项显式选择轻度降噪、DPDFNet 降噪或 DPDFNet 后接 Seed-VC。
Seed-VC 统一音色必须先做模型降噪；同一固定参考贯穿所有已录页面。
参考可来自当前有效页面录音或受限上传；导出固定原片段和参考的不可变快照。

沿用研究案例已实践的 DPDFNet8 48 kHz HR/12 dB 与 Seed-VC 44.1 kHz 源 F0 配置。
依赖、代码版本、权重修订及适配明确固定；只在显式准备步骤下载权重，服务离线运行。
模型失败须明确失败，不静默回退原声。原片、单页预览、UUID 页面绑定不改变。
最终响度均衡继续执行；模型采样网格的小尾差只补齐/裁去末端，不做变速。
媒体时长保持不被描述为逐音素同步保证。
